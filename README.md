# Bareman-Tracker

RP2350 custom PCB with a LR1121 with this pinout:

| Pin | Function |
| --- | -------- |
| 6   | SPI0 SCK |
| 4   | SPI0 MOSI|
| 7   | SPI0 MISO|
| 5   | SPI0 NSS |
| 0   | LR1121 BUSY |
| 1   | LR1121 NRESET |

With GPS on UART here:

| Pin | Function |
| --- | -------- |
| 16 | UART0 TX |
| 17 | UART0 RX |

LEDs on:

| Pin | Function |
| --- | -------- |
| 12  | STATUS   |
| 13  | TX       |
| 14  | RX       |
